# Security Policy

Thank you for improving the security of **Pixiv OAuth Token**. We take security very seriously, especially since this tool handles user authentication tokens.

## Supported Versions

Currently, only the latest version of the application and web interface is supported with security updates. Please ensure you are using the most recent release before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues or discussions.** If you believe you have found a security vulnerability in Pixiv OAuth Token (such as token leakage, XSS, or insecure data handling), please report it directly to the maintainer.

**How to report:**
1. Send an email to **fatonyahmadfauzi@gmail.com** with the subject `[SECURITY] Vulnerability Report: Pixiv OAuth Token`.
2. Include a detailed description of the vulnerability.
3. Provide steps to reproduce the issue so we can verify it.

We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress. If the vulnerability is verified, we will release a patch immediately.
