Project Overview

This project provides helpers to exchange and refresh Pixiv OAuth tokens, plus build scripts to produce Portable/Setup artifacts on Windows.

Available Modes

  • CLI: pixiv_login.py
  • GUI: pixiv_login_gui.py
  • Web: static UI + serverless /api/token

Requirements

  • Python 3.11+
  • Dependencies: requests, pyinstaller
  • Windows build toolchain for setup installer
