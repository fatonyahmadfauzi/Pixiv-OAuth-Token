Get Started with Pixiv OAuth Tutorial

Follow each step from login to token exchange so the process is easier on desktop and mobile.

Tutorial Steps

Open Login Page

Open the Pixiv login page from the web console tool.

Continue Login

Continue login until Pixiv redirects you to the callback page.

Open Console

Open DevTools/Console to capture the pixiv callback URL.

Copy pixiv URL

Copy the callback URL that contains Pixiv authorization code.

Paste URL / Code

Paste callback URL or code into the OAuth console input.

Exchange Token

Click Exchange Token, then copy access_token and refresh_token.

Back to OAuth Console
