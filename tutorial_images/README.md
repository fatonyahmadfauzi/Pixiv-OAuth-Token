# Tutorial Images

Place tutorial screenshots here in ordered PNG filenames so the Tutorial menu can load them automatically.

Recommended naming:
- `01-open-login-page.png`
- `02-continue-login.png`
- `03-open-console.png`
- `04-copy-pixiv-url.png`
- `05-paste-url-code.png`
- `06-exchange-token.png`

The app reads `tutorial_images/*.png` in filename order.
