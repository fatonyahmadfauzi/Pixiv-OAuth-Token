## [1.0.3] - 2026-03-26 
### ✨ 변경됨
- 런타임/버전 도구 및 생성된 매니페스트 전체에서 기본 로컬 빌드 레이블을 `REL-LOCAL`에서 `BUILD-UNKNOWN`로 대체했습니다.
- 이제 GUI에는 **Changelog** 상단 메뉴 작업과 명시적인 버전 확인 항목이 있는 **Version** 드롭다운이 포함됩니다.
- 업데이트 팝업 작업(**업데이트** / **나중에**)을 사용하여 GUI에 자동 시작 버전 확인을 추가하고 고정된 설정/이식 가능한 배포에 대한 업데이트 흐름 처리를 추가했습니다.
- 버전 범프(`patch/minor/major`) 시 빌드 코드 생성을 Unix 스타일 `REL-U<unix_ms>`로 업데이트했습니다.

## [1.0.2] - 2026-03-23 
### ✨ 추가됨
- **디버그 콘솔(GUI)**
GUI 헤더의 오른쪽 상단에 있는 전용 `⚙ Debug` 버튼을 누르면 모든 애플리케이션 이벤트를 실시간으로 기록하는 어두운 테마의 터미널 콘솔이 열립니다. 캡처된 이벤트에는 앱 시작, 언어 변경, 모든 버튼 클릭(로그인 열기, 토큰 교환, 토큰 새로 고침, 액세스/새로 고침 토큰 복사, 자습서), HTTP 요청 상태(전송/성공/실패), PKCE 흐름 단계, 클립보드 작업, 구성 쓰기 및 경고가 포함됩니다. 모든 디버그 메시지는 지원되는 11개 언어로 완전히 현지화되었습니다. 콘솔은 열려 있는 동안 새 메시지의 라이브 스트리밍, 세션 시작 시 기록 로그 미리 채우기, **모두 복사** 버튼 및 **지우기** 버튼을 지원합니다.

## [1.0.1] - 2026-03-22
### ✨ 추가됨
- **릴리스용 스마트 README 클리너**
배포 가능한 `.zip`을 컴파일할 때 `` 파일에서 지역화 언어 섹션을 자동으로 제거하고 내부 링크를 절대 GitHub 링크로 바꿉니다.
- **통합 이중 설치 프로그램 지원**
InnoSetup 빌더 스크립트는 이제 최종 사용자에게 선택적으로 독립형 CLI 또는 그래픽 GUI를 설치하라는 메시지를 표시하는 통합 설치 프로그램을 생성합니다.

### 🐞 수정됨
- **설치 프로그램 빌드 경로 확인**
구성된 `scripts\` 디렉터리 내에서 직접 빌드 파일을 생성하여 `iscc`이 `app\pixiv_oauth.ico`을 찾지 못하는 `make_installer_iss_dual.py`의 중요한 경로 불일치 문제를 수정했습니다.
