## [1.0.4] - 2026-03-29

### 🐞修正済み
- **ポータブル CLI/GUI — 更新後のバージョン ロールバック**: `VERSION_FILE` と `CONFIG_FILE` は `Path(__file__)` を使用して解決されました。凍結 (PyInstaller onefile) モードでは一時 `_MEIPASS` ディレクトリを指します。このディレクトリは、アプリが終了すると破棄されます。どちらのファイルも `_app_dir()` / `app_dir()` を使用して解決されるようになり、実際の `.exe` を含むフォルダーが正しく返され、再起動後もバージョンの同一性が維持されます。
- **CLI — exe ではなく一時 `.py` を更新する**: 凍結された実行可能ファイルとして実行している場合、`_self_update()` は実際の `.exe` を置き換えるのではなく、一時ディレクトリ内の抽出された `.py` を上書きしていました。この関数は `is_frozen` を検出し、新しい実行可能ファイルを直接ダウンロードし、`.bat` アップデーター スクリプト (GUI と同じメカニズム) を介して置き換えます。

### ✨追加しました
- **アーキテクチャ対応の自動更新 (CLI + GUI)**: ポータブル更新フローとセットアップ更新フローの両方で、実行中の実行可能ファイル (`x64`、`x86`、`ARM64`、または汎用) のアーキテクチャをファイル名から検出し、正確に一致するバリアントを `downloads/` フォルダーからダウンロードすることで、更新中の偶発的なアーキテクチャの不一致を防止します。
- **CLI セットアップ インストーラーの更新フロー**: CLI は、セットアップ インストールの GUI の動作をミラーリングするようになりました。`Program Files` から実行する場合、最新の `.exe` セットアップ インストーラーをダウンロードし、インプレース バイナリ スワップを試みるのではなく、サイレント (`/VERYSILENT /NORESTART`) で実行されます。

## [1.0.3] - 2026-03-26

- ランタイム/バージョン ツールおよび生成されたマニフェストにわたって、デフォルトのローカル ビルド ラベルを `REL-LOCAL` から `BUILD-UNKNOWN` に置き換えました。
- GUI には、**Changelog** トップメニュー アクションと、明示的なバージョン チェック エントリを含む **Version** ドロップダウンが含まれるようになりました。
- 更新ポップアップ アクション (**更新** / **後で**) を使用した GUI での自動起動バージョン チェックと、凍結されたセットアップ/ポータブル ディストリビューションの更新フロー処理を追加しました。
- バージョン バンプ (`patch/minor/major`) でビルド コード生成を Unix スタイル `REL-U<unix_ms>` に更新しました。

## [1.0.2] - 2026-03-23 
### ✨追加しました
- **デバッグ コンソール (GUI)**
GUI ヘッダーの右上隅にある専用の `⚙ Debug` ボタンを使用すると、ダークテーマのターミナル コンソールが開き、すべてのアプリケーション イベントがリアルタイムで記録されます。キャプチャされるイベントには、アプリの起動、言語の変更、すべてのボタンのクリック (オープン ログイン、交換トークン、リフレッシュ トークン、コピー アクセス/リフレッシュ トークン、チュートリアル)、HTTP リクエストの状態 (送信/成功/失敗)、PKCE フロー ステップ、クリップボード操作、構成の書き込み、警告が含まれます。すべてのデバッグ メッセージは、サポートされている 11 言語すべてに完全にローカライズされています。コンソールは、開いている間の新しいメッセージのライブ ストリーミング、セッション開始からの履歴ログの事前入力、**すべてコピー** ボタン、**クリア** ボタンをサポートしています。

## [1.0.1] - 2026-03-22
### ✨追加しました
- **リリース用のスマート README クリーナー**
配布可能な `.zip` をコンパイルするときに、ローカリゼーション言語セクションを `__p1__` ファイルから自動的に削除し、内部リンクを絶対 GitHub リンクに置き換えます。

### 🐞修正済み
- **インストーラーのビルド パスの解像度**
構成された `scripts\` ディレクトリ内にビルド ファイルを直接生成することにより、`iscc` が `app\pixiv_oauth.ico` を見つけることができないという `make_installer_iss_dual.py` のクリティカル パスの不一致の問題を修正しました。
