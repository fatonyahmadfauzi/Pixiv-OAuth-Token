## [1.0.5] - 2026-04-03

### ✨ 追加

- **インターネット対応 GUI スタートアップ**
メインの GUI ウィンドウを起動する前に、スマート `NetLoadingScreen` スプラッシュ画面が飛行前のインターネット接続チェックを実行するようになりました。接続が見つからない場合は、接続されるまでバックグラウンドで安全に再試行します。さらに、アクティブなランタイム モニターは、使用中に接続が途中で切断された場合、読み込み画面に戻るアラートを表示します。
- **ネイティブ GUI ドキュメント モーダル**
重要なドキュメントの外部ブラウザのリダイレクトを置き換えました。 **変更ログ**、**利用規約**、**プライバシー ポリシー**が、ネイティブで動的、クリーンな `tkinter` ダイアログ ウィンドウ内に表示されるようになりました (GitHub リポジトリから直接非同期で取得されます)。
- **包括的なターミナルのローカリゼーション**
インタラクティブな GitHub CLI インターフェイス (問題ナビゲーション) とすべての端末ベースの法務/サポート レイアウトは、サポートされている 11 言語すべてにわたって確実にローカライズされています。

### ✨ 変更されました

- **再設計されたCLIの美学**
従来の装飾的なボックスの境界線が削除され、非常にクリーンで最新の左揃えの端末表示になりました。
- **自動デジタルコード署名**
`sign_auto.bat` パイプラインを大幅にアップグレードしました。このスクリプトは、Windows SDK の奥深くで `signtool.exe` を動的に自動検出するようになり、生成されたすべてのビルド (インストーラーのセットアップとダウンロード `_latest` エイリアスを含む) に自己署名証明書を同時に簡単に適用して、基本的な SmartScreen の「不明な発行元」フラグを抑制します。

### 🐞 修正されました

- **インストーラー プロパティのバグ**
インストーラー `Setup.exe` が Windows プロパティに `0.0.0.0` を表示する異常を修正しました。ビルダーは、コンパイル中に厳密な PE `VersionInfoVersion` ヘッダーを適切に挿入し、レンダリング時にすぐに正確に一致するリリース番号 (e.g.、1.0.5.0) を反映するようになりました。

## [1.0.4] - 2026-03-29

### 🐞 修正されました

- **ポータブル CLI/GUI — 更新後のバージョン ロールバック**: `VERSION_FILE` と `CONFIG_FILE` は `Path(__file__)` を使用して解決されました。これは、凍結 (PyInstaller onefile) モードでは、一時 `_MEIPASS` ディレクトリ (アプリが終了すると破棄されるディレクトリ) を指します。どちらのファイルも `_app_dir()` / `app_dir()` を使用して解決されるようになり、実際の `.exe` を含むフォルダーが正しく返され、再起動後もバージョンの同一性が維持されます。
- **CLI — アップデートは exe ではなく一時 `.py` を上書きしました**: 凍結された実行可能ファイルとして実行すると、`_self_update()` は実際の `.exe` を置き換えるのではなく、一時ディレクトリ内の抽出された `.py` を上書きしていました。この関数は `is_frozen` を検出し、新しい実行可能ファイルを直接ダウンロードし、`.bat` アップデータ スクリプト (GUI と同じメカニズム) を介して置き換えます。

### ✨ 追加

- **アーキテクチャを意識した自動更新 (CLI + GUI)**: ポータブル更新フローとセットアップ更新フローの両方で、実行中の実行可能ファイル (`x64`、`x86`、`ARM64`、または汎用) のアーキテクチャをファイル名から検出し、正確に一致するバリアントを `downloads/` フォルダーからダウンロードすることで、更新中の偶発的なアーキテクチャの不一致を防ぎます。
- **CLI セットアップ インストーラーの更新フロー**: CLI は、セットアップ インストールの GUI 動作をミラーリングするようになりました。`Program Files` から実行する場合、最新の `.exe` セットアップ インストーラーをダウンロードし、インプレース バイナリ スワップを試みるのではなく、サイレント (`/VERYSILENT /NORESTART`) で実行されます。

## [1.0.3] - 2026-03-26

### ✨ 変更されました

- ランタイム/バージョン ツールおよび生成されたマニフェストにわたって、デフォルトのローカル ビルド ラベルを `REL-LOCAL` から `BUILD-UNKNOWN` に置き換えました。
- GUI には、**Changelog** トップメニュー アクションと、明示的なバージョン チェック エントリを含む **Version** ドロップダウンが含まれるようになりました。
- 更新ポップアップ アクション (**更新** / **後で**) による自動起動バージョン チェックを GUI に追加し、凍結されたセットアップ/ポータブル ディストリビューションの更新フロー処理を追加しました。
- バージョン バンプ (`patch/minor/major`) でビルド コード生成を Unix スタイル `REL-U<unix_ms>` に更新しました。

## [1.0.2] - 2026-03-23

### ✨ 追加

- **デバッグ コンソール (GUI)**
GUI ヘッダーの右上隅にある専用の `⚙ Debug` ボタンを使用すると、ダークテーマのターミナル コンソールが開き、すべてのアプリケーション イベントがリアルタイムで記録されます。キャプチャされるイベントには、アプリの起動、言語の変更、すべてのボタンのクリック (オープン ログイン、交換トークン、リフレッシュ トークン、コピー アクセス/リフレッシュ トークン、チュートリアル)、HTTP リクエストの状態 (送信/成功/失敗)、PKCE フロー ステップ、クリップボード操作、構成の書き込み、警告が含まれます。すべてのデバッグ メッセージは、サポートされている 11 言語すべてに完全にローカライズされています。コンソールは、開いている間の新しいメッセージのライブ ストリーミング、セッション開始からの履歴ログの事前入力、**すべてコピー** ボタン、**クリア** ボタンをサポートしています。
