## [1.0.5] - 2026-04-03

### ✨ Добавлено

- **Запуск GUI с поддержкой Интернета**
Перед запуском главного окна GUI интеллектуальная заставка `NetLoadingScreen` теперь выполняет предполетную проверку подключения к Интернету. Если соединение не найдено, оно безопасно повторяет попытку в фоновом режиме до тех пор, пока не будет установлено соединение. Кроме того, активный монитор времени выполнения будет отображать предупреждение, возвращающееся к экрану загрузки, если соединение прерывается на полпути во время использования.
- **Встроенные модальные окна документации GUI**
Заменены перенаправления внешнего браузера для важной документации. **Журнал изменений**, **Правила и условия** и **Политика конфиденциальности** теперь отображаются в собственных, динамических и чистых диалоговых окнах `tkinter` (асинхронная выборка прямо из репозитория GitHub).
- **Комплексная локализация терминалов**
Интерактивный интерфейс GitHub CLI (навигация по проблемам) и все макеты юридической и технической поддержки на базе терминала теперь достоверно локализованы на всех 11 поддерживаемых языках.

### ✨ Изменено

- **Изменена эстетика CLI**
Удалены устаревшие декоративные рамки, что сделало дисплей терминала более чистым, модернизированным и выровненным по левому краю.
- **Автоматическое подписание цифрового кода**
Существенно обновлен конвейер `sign_auto.bat`. Теперь сценарий динамически автоматически обнаруживает `signtool.exe` глубоко внутри Windows SDK, без особых усилий применяя самозаверяющий сертификат одновременно ко всем созданным сборкам (включая настройки установщика и псевдонимы загрузки `_latest`), чтобы подавить базовые флаги SmartScreen «Неизвестный издатель».

### 🐞 Исправлено

- **Ошибка свойств установщика**
Исправлена ​​аномалия, из-за которой установщик `Setup.exe` отображал `0.0.0.0` в свойствах Windows. Компоновщик теперь правильно внедряет строгие заголовки PE `VersionInfoVersion` во время компиляции, чтобы отразить точно соответствующий номер выпуска (e.g., 1.0.5.0) сразу после рендеринга.

## [1.0.4] - 2026-03-29

### 🐞 Исправлено

- **Portable CLI/GUI — откат версии после обновления**: `VERSION_FILE` и `CONFIG_FILE` были разрешены с помощью `Path(__file__)`, который в замороженном режиме (один файл PyInstaller) указывает на временный каталог `_MEIPASS` — каталог, который уничтожается при закрытии приложения. Оба файла теперь разрешаются с помощью `_app_dir()`/`app_dir()`, который правильно возвращает папку, содержащую фактический `.exe`, обеспечивая сохранение идентичности версии при перезапуске.
- **CLI — Обновление перезаписывало temp `.py` вместо exe**: при работе в качестве замороженного исполняемого файла `_self_update()` перезаписывал извлеченный `.py` внутри временного каталога вместо замены фактического `.exe`. Теперь функция обнаруживает `is_frozen` и загружает новый исполняемый файл напрямую, заменяя его с помощью сценария обновления `.bat` (тот же механизм, что и GUI).

### ✨ Добавлено

- **Автоматическое обновление с учетом архитектуры (CLI + GUI)**: как переносимые, так и установочные потоки обновления теперь определяют архитектуру работающего исполняемого файла (`x64`, `x86`, `ARM64` или общий) по имени файла и загружают точно соответствующий вариант из папки `downloads/`, предотвращая случайное несоответствие архитектуры во время обновлений.
- **CLI поток обновления установщика установки**: CLI теперь отражает поведение GUI для установочных установок — при запуске с `Program Files` он загружает последнюю версию установщика установки `.exe` и запускает ее автоматически (`/VERYSILENT /NORESTART`) вместо попытки двоичной замены на месте.

## [1.0.2] - 2026-03-23

### ✨ Добавлено

- **Консоль отладки (GUI)**
Специальная кнопка `⚙ Debug` в правом верхнем углу заголовка GUI открывает консоль терминала в темной тематике, которая регистрирует каждое событие приложения в режиме реального времени. Записанные события включают в себя: запуск приложения, изменение языка, нажатие всех кнопок (Открыть вход, Токен Exchange, Токен обновления, Копировать токен доступа/обновления, Учебное пособие), состояния HTTP-запроса (отправка/успех/неудача), шаги потока PKCE, операции с буфером обмена, записи конфигурации и предупреждения. Все отладочные сообщения полностью локализованы на всех 11 поддерживаемых языках. Консоль поддерживает потоковую передачу новых сообщений при открытии, предварительное заполнение исторических журналов с начала сеанса, кнопку **Копировать все** и кнопку **Очистить**.
