## [1.0.4] - 2026-03-29

### 🐞 Исправлено
- **Portable CLI/GUI — откат версии после обновления**: `VERSION_FILE` и `CONFIG_FILE` были разрешены с помощью `Path(__file__)`, который в замороженном режиме (один файл PyInstaller) указывает на временный каталог `_MEIPASS` — каталог, который уничтожается при закрытии приложения. Оба файла теперь разрешаются с помощью `_app_dir()`/`app_dir()`, который правильно возвращает папку, содержащую фактический `.exe`, обеспечивая сохранение идентичности версии при перезапуске.
- **CLI — обновление перезаписало temp `.py` вместо exe**: при работе в качестве замороженного исполняемого файла `_self_update()` перезаписывал извлеченный `.py` внутри временного каталога вместо замены фактического `.exe`. Теперь функция обнаруживает `is_frozen` и напрямую загружает новый исполняемый файл, заменяя его с помощью сценария обновления `.bat` (тот же механизм, что и в графическом интерфейсе).

### ✨ Добавлено
- **Автоматическое обновление с учетом архитектуры (CLI + GUI)**: как переносимые, так и установочные потоки обновления теперь определяют архитектуру работающего исполняемого файла (`x64`, `x86`, `ARM64` или общий) по имени файла и загружают точно соответствующий вариант из папки `downloads/`, предотвращая случайное несоответствие архитектуры во время обновлений.
- **Последовательность обновления установщика установки CLI**: CLI теперь отражает поведение графического интерфейса для установки установки — при запуске с `Program Files` он загружает последнюю версию установщика установки `.exe` и запускает ее автоматически (`/VERYSILENT /NORESTART`) вместо попытки двоичной замены на месте.

## [1.0.3] - 2026-03-26 
### ✨ Изменено
— Метка локальной сборки по умолчанию заменена с `REL-LOCAL` на `BUILD-UNKNOWN` в инструментах среды выполнения/версии и сгенерированных манифестах.
- Графический интерфейс теперь включает в себя действие верхнего меню **Журнал изменений** и раскрывающийся список **Версия** с явной записью проверки версии.
- Добавлена ​​автоматическая проверка версии при запуске в графическом интерфейсе с всплывающими действиями при обновлении (**Обновить** / **Позже**), а также обработка потока обновлений для зависших установок/переносимых дистрибутивов.
— Обновлено создание кода сборки в стиле unix `REL-U<unix_ms>` при обновлении версии (`patch/minor/major`).

## [1.0.2] - 2026-03-23 
### ✨ Добавлено
- **Консоль отладки (графический интерфейс)**
Специальная кнопка `⚙ Debug` в правом верхнем углу заголовка графического интерфейса открывает консоль терминала в темной тематике, которая регистрирует каждое событие приложения в режиме реального времени. Записанные события включают в себя: запуск приложения, изменение языка, нажатие всех кнопок (Открыть вход, Токен Exchange, Токен обновления, Копировать токен доступа/обновления, Учебное пособие), состояния HTTP-запроса (отправка/успех/неудача), шаги потока PKCE, операции с буфером обмена, записи конфигурации и предупреждения. Все отладочные сообщения полностью локализованы на всех 11 поддерживаемых языках. Консоль поддерживает потоковую передачу новых сообщений при открытии, предварительное заполнение исторических журналов с начала сеанса, кнопку **Копировать все** и кнопку **Очистить**.
